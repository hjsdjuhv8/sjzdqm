# 三角洲行动 · 改枪码库

> 将我改的枪的改枪码，实时分享到网站上，使大家能够看到我的改枪码。

一个给抖音/短视频博主用的改枪码分享站：**观众在站内搜索 → 一键复制改枪码 → 进游戏粘贴**，
你自己则通过一个带密码的后台**批量粘贴导入**，不用再手写文案。

零依赖：只用 Python 标准库 + SQLite，前端是纯 HTML/CSS/JS，没有构建步骤、不用装 npm。

**线上永久链接**：用 GitHub 存代码、EdgeOne Pages 分发、绑自己的域名 ——
详见 [永久链接方案-GitHub+EdgeOne.md](永久链接方案-GitHub+EdgeOne.md)。

## 快速开始

**Windows：双击 start.bat**，自动找 Python、启动服务、打开浏览器。
它会监听所有网卡，同一 WiFi 下的手机可以直接访问。

命令行方式：

```bash
cd deltaforce-codes
python3 server.py                # 本机访问 http://127.0.0.1:8000
python3 server.py --host 0.0.0.0 --port 8000  # 允许局域网/公网访问
python3 server.py --port 8080    # 换端口
```

要让**别人**访问（粉丝、观众），有两个文档：

- **[怎么拿到链接-最简单方案.md](怎么拿到链接-最简单方案.md)** —— 推荐先看这个：
  点「导出静态站」拿到一个 zip，传到静态托管，得到一个永久链接，粉丝点开就能用（不需要你电脑开机）
- [部署指南-让别人访问.md](部署指南-让别人访问.md) —— 想跑完整后端（带复制统计）时看

首次启动会自动：
1. 建库 `data/codes.db`
2. 生成管理密码，写到 `data/.admin-password`，**并在终端打印一次**
3. 写入 3 条示例数据（正式用之前删掉）

- 前台：`http://127.0.0.1:8000/`
- 后台：`http://127.0.0.1:8000/admin`

> Windows 上如果 `python3` 不可用，用 `python` 或你本机的绝对路径。

## 你的日常工作流

### 导入一批新码（约 10 秒）

1. 游戏里配好枪 → 点「分享」，码进剪贴板
2. 打开 `/admin` → 粘贴到文本框（**多把一起贴，一行一条**）
3. 点「解析预览」→ 确认枪名/模式识别对不对 → 点「确认导入」

解析器能处理这些真实粘贴形态：

| 粘贴内容 | 结果 |
|---|---|
| `腾龙突击步枪-全面战场-6IL87QG013CE082VBOHIS` | 枪名、模式、码都正确 |
| `AK-12突击步枪-全面战场-xxx` | 带连字符的枪名不会被切坏 |
| `【三角洲行动】K416-烽火地带-xxx` | 自动剥掉 `【】`前缀和话题标签 |
| `1. M249轻机枪-全面战场-xxx` | 自动剥掉序号 |
| `SCAR-H战斗步枪-5116089223937551183-烽火地带` | 纯数字老式码也认 |
| `突击步枪-6GD1CM004J7LV61QLMNR9` | 枪名被截断 → 标红，可在预览框里手填 |

识别不了的行会标红并跳过，不影响其余条目。已存在的码再次导入会**覆盖更新**（复制次数保留）。

### 单条修正

后台表格里所有字段都能直接改，改完点该行「保存」。状态可切「上架 / 草稿」，草稿不在前台显示。

## 常用维护

```bash
python3 server.py --reset        # 清空数据库重建（清理测试数据）
cat data/.admin-password         # 查看管理密码
```

- **整库备份**：后台点「导出全部」，得到一行一条的纯文本；或直接备份整个 `data/` 目录。
- **换密码**：删掉 `data/.admin-password` 后重启，会生成新的。
- **加枪名别名**：改 `server.py` 里的 `ALIAS` 字典，粘贴时的俗称（如 `腾龙` → `腾龙突击步枪`）就会自动归一。`MODE_HINT` 控制没写模式时按枪名猜默认模式。

## 改枪码长什么样（解析规则）

形如 `枪名-模式-码`。早期也有 `枪名-纯数字码` 的老格式。解析思路是：
**先在整行里找出唯一那串「不含中文、长度≥6」的内容当作码，剩下部分再切枪名与模式**。
所以顺序颠倒、多了前缀后缀、混了话题标签，都不影响。

## 安全设计

- 后台所有写操作都要登录态（HttpOnly Cookie，7 天有效，重启服务即失效）
- 登录失败同一 IP 10 分钟内超过 10 次会锁 10 分钟
- 复制计数只存 IP 的 SHA-256 前 16 位，不存任何身份信息
- 静态文件做了路径穿越防护；单次请求体上限 32MB
- `data/.admin-password` 权限设为 600，密码不会进前端代码

⚠️ 上线前请务必做的两件事：

1. **改掉示例数据**（`python3 server.py --reset` 或后台逐条删）
2. **套 HTTPS**。用 nginx / Caddy 反代到 `127.0.0.1:8000`，管理密码绝不能裸奔在明文 HTTP 上。Caddy 只要三行：
   ```
   your-domain.com {
       reverse_proxy 127.0.0.1:8000
   }
   ```

## 合规红线（建站前先看）

- 站内**只做展示 + 复制文本**，不出现"一键导入游戏""自动改枪"这类功能与措辞
- 不收集任何人的游戏账号、密码、openid、token
- 页脚保留声明：素材与数据版权归腾讯所有，本站仅作玩家交流展示
- 不宣称"官方授权"

改枪码是游戏服务器签发的凭证，**不代表账号私密**（否则无法分享）；但它也不是站内能算出来的。
所以本站的定位是「你整理、你分享」，而不是「自动生成」。这也是这个方案能长期稳定运行的前提。
